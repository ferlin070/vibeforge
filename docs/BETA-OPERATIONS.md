# Workspace operations and localization

Workspace operations aggregates only the current browser's validated project records. It prioritizes open critical/high bugs, pending reviews and blocked tasks, and links to the corresponding project quality or next-action view. It is not a privileged platform admin console. No new database grants or platform-wide user listing are introduced. The exported JSON contains aggregate counts only, not project content, identifiers or credentials. The counts are advisory and based on recorded evidence, not independent verification.

Malay and English navigation and operations text can be selected in the sidebar. The preference is browser-local, separate from project data. Route IDs and project content are unchanged. English remains the default. Landing pages, individual tool modules, generated artifacts and backend error messages remain English; this increment is not full localization.

Unit and browser regression tests cover priorities, aggregate export, route compatibility, language persistence and preservation of project data. No paid service or billing integration is included.
