# RC10 — Curated template library

Eight free project starters cover hospitality, retail, education, business, marketing, automation and field services. Search and category filters select an editable brief for the existing three-step wizard. The wizard uses the shared agent registry. Creating a project allocates a new ID and does not copy approvals, evidence, repository bindings or assignments from another project.

This is a first-party template library, not a transactional marketplace. No purchases, publishing by third parties, payout accounts or payment integration are enabled. Review templates against actual project needs. Unit and browser tests cover template validation, filtering, agent selection and independent project creation.
