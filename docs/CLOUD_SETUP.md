# Optional cloud setup
Create a dedicated Supabase project; do not reuse a different product database. Review and run docs/cloud-schema.sql once in the new SQL editor. It includes explicit grants and owner-only RLS. Enable email/password auth and email confirmation, configure allowed redirect/Site URL and email delivery. Set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY in local/Vercel environment and rebuild. Use publishable key only, never service role. No credentials in GitHub. Verify two separate accounts cannot read/write each other's rows. Login session is in memory, expires and requires sign-in again. Cloud snapshots are explicit backups/restores, not automatic multi-device synchronization. Local data stays in the browser on logout. Enable auth abuse protections before public release.
