# VibeForge — MVP candidate v0.3.0
Source implementation: local-first project workspace, deterministic and real BYOK OpenAI blueprint generation, nine editable documents, assumptions/questions, user approval, validated dependency graph, task context export, manual evidence/review, Markdown, JSON and ZIP kit, optional Supabase auth and cloud snapshot CRUD, owner-only RLS SQL. Legacy HTML retained.
Validation: direct authoring checks for blueprint, context, dependency blocking and cycle rejection passed. Test files added; dependency install, Next.js build, browser E2E, live API and two-account RLS tests pending. No live cloud resources configured; no production deploy.
Known limits: AI generation uses user's key per request; provider model access and budget vary. One generation can time out; no durable AI queue. Manual approval is not independent verification. Cloud snapshots explicitly saved/restored, not automatic sync. No repository ingestion, billing, team collaboration, live research or agent execution. These are post-MVP or require infrastructure and testing.

Additional direct checks: review invalidation cascade and ZIP signatures/file count passed. External ZIP extraction and browser download untested.
