# Multi-provider AI engine v0.5

Five hosted provider adapters: OpenAI Responses, Anthropic Messages, Google Gemini generateContent, DeepSeek and OpenRouter Chat Completions. Model IDs are user-selected; examples may be unavailable. No arbitrary URLs or automatic retries. Keys held in memory, cleared after request, never persisted by app. External provider receives project input and key, and may bill usage. Mock contract tests are not live API validation. Ollama deferred: hosted Vercel cannot access user localhost; plan a separate local/self-hosted connector. Manual mode remains available. No schema changes or production release.
