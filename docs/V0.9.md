# v0.9 Quality Studio

Local bug tracker, best-effort log redaction, pattern-based investigation hints, deterministic debug/security handoff and acceptance-derived test plans. Read-only GitHub Actions run import filtered to scanned repository commit, optional read-only token, no code execution. Release gates combine manually recorded evidence, reviewed tasks, severity, imported CI outcomes and rollback plan. Results are advisory, not independent or exhaustive verification. Specification changes reset release checks and CI snapshot. No automatic deployment or background agent execution. Existing manual cloud snapshot schema unchanged. Preview only.
