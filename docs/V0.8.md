# v0.8 Mission Control

Manual orchestration of external coding agents with nine specialist roles and nine agent profiles. Assignment, explicit recorded handoff, external agent report and human review share blueprint evidence and dependency gates. Specification or project-memory changes clear stale assignments and reviews. Reopen clears downstream evidence and handoff markers. Activity log is bounded local history, not an immutable audit trail. No autonomous execution, provider API calls, remote agent queue, background jobs or deployment actions. Existing Supabase snapshots include local mission state when saved manually. Preview only.
