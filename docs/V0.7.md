# v0.7 Project memory and context engineering

Local-first memory entries, three bounded read-only context checkpoints with export and comparison, conservative impact assessment, dependency-aware resume and deterministic agent-specific prompts. Checkpoint exports include historical evidence and project data; review before sharing. No database migration. Preview only.
