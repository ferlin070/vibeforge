# RC2 Phase 4 — supply chain and CI

Node 22+ is required; .nvmrc selects 22. The npm-generated lockfile was obtained from the GitHub Actions runner because local DNS resolution of registry.npmjs.org was unavailable. The bootstrap runner emitted 106 numbered chunks and SHA-256 0f31041c9a3047710f0cba7587dd827b3c02e4aa7aac85a3edc65f43cfc0649b; the runner verified the reconstructed bytes before installing. The temporary bootstrap/extraction steps have been removed from permanent CI.

ESLint uses the Next.js Core Web Vitals flat config. Three existing effects in app/page.jsx have narrowly scoped, documented rule exceptions: browser-only hydration, persistence-error notices, and resetting the draft editor only when selected project or saved document changes. The editor effect retains its intentional dependencies to avoid discarding unsaved work. No global hooks rule is disabled. The JSX apostrophe is escaped.

Prettier formatting is isolated in commit fb222ee; all 50 changed file blob hashes matched the runner output. Formatting was repeated after the first transfer encountered log masking of test fixtures. The generated lockfile is deliberately excluded from Prettier to preserve npm's exact output. Dependabot checks npm and GitHub Actions weekly. CI uses npm ci, strict lint, format check, npm test, build and production dependency audit; action refs remain pinned and permissions read-only.

The previous setup-node SHA failed runner resolution; v6 SHA was obtained from the official actions/setup-node tag and verified by the runner. The temporary bootstrap audit returned zero production dependency vulnerabilities. The pinned checkout action emits a Node 20 deprecation warning; it still completed and Dependabot is configured to review action updates. This is time-dependent, not a guarantee against undisclosed vulnerabilities. No deployment, real credentials, accounts or database changes.
