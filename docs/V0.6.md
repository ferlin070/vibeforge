# v0.6 Repository intelligence and custom gateways

Read-only GitHub inventory pinned to default-branch commit: metadata, tree, root package.json dependency names, heuristic checks. Public repositories without token; optional read-only user token for private repositories. No execution or full source audit. Inventory stored in local project; manual cloud snapshot/export may include private filenames. Explicit opt-in to send inventory to selected AI gateway. Custom OpenAI chat/responses and Anthropic messages (x-api-key or Bearer): only public HTTPS DNS host on default port, IPv4 DNS validation and pinned address with hostname TLS validation, no redirects, capped output and timeout. No local or private endpoint; no arbitrary headers. Keys never persisted by app. External gateway can retain input or bill usage. Real gateway interoperability requires user testing. No production deployment or database changes.
