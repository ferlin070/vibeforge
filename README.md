# VibeForge
A Ghazwah Group product — From idea to production.

Independent greenfield project. This starter is a local-first planning prototype, not an AI-connected production application.

Open `index.html` in a browser. Enter an idea, select the project type and target agent, then generate a deterministic planning brief and coding instructions. Copy or export the result. Drafts are stored in browser local storage.

See `AGENTS.md` and `docs/BLUEPRINT.md` for implementation instructions.
